# PocketLink Android 1.7.0 / Windows 1.6.0

## Изменения

- Главная страница: быстрые действия, буфер, питание, файлы, звук, окна, Bluetooth, микрофон, веб-камера и устройства. Файлы доступны и внутри раздела «ПК». Общие настройки содержат настройки; шестерёнка открывает параметры текущей функции.
- Тачпад: один тап — левая кнопка, тап двумя пальцами — правая; удержание одним пальцем зажимает левую кнопку для выделения и перетаскивания. Отдельные кнопки сохранены. Выбор выхода звука доступен с пульта.
- Трансляция ПК сохраняется при повороте телефона; в горизонтальном положении работающая трансляция занимает весь экран. Управление касаниями можно отключить.
- Соединение: тяжёлые запросы выполняются отдельно от чтения сообщений; исправлено ожидание подтверждения буфера, блокировавшее его обработку. Android использует доступную домашнюю Wi-Fi-сеть для локальных сокетов и направленного поиска. Это не отменяет запрет LAN в настройках VPN.
- Программы: поиск по названию; удалены битые ярлыки, интернет-ссылки и ярлыки без существующего EXE. Некоторые приложения Microsoft Store и игры со специальными ссылками могут отсутствовать.
- YouTube: постоянный защищённый ключ браузера на ПК, проверка свежести состояния вкладки, обложки можно получать через ПК. Chrome/Яндекс обновлены до расширения 1.3.0; подписанный Firefox 1.3.0 сохранён. После первого обновления Windows ключ потребуется вставить один раз, дальше он сохраняется.
- Фото и видео доступны в галерее ПК. Передача использует исходное имя; слишком длинные имена сокращаются с сохранением расширения. При совпадении имён добавляется номер, чтобы не затереть другой файл.
- Windows: собственное окно и значок вместо запуска Edge в режиме приложения. Старый закреплённый Edge нужно открепить; новый PocketLink закрепить заново. Нужен Microsoft WebView2 Runtime.
- Windows 1.6.0: после проверенной загрузки кнопка «Установить и перезапустить» заменяет файлы и запускает программу. При ошибке замены выполняется откат. Настройки и сопряжения остаются отдельно. В более старой программе этого установщика ещё нет: Windows 1.6.0 нужно один раз распаковать вручную.
- Новая иконка по выбранному варианту №2.

## Телефон как веб-камера

На ПК открой «Экран телефона», подключи телефон к ADB через USB или Wi-Fi и нажми «Использовать как веб-камеру». Для камеры нужен Android 12+ и установленный OBS Studio с виртуальной камерой. Кнопка установки открывает официальный сайт OBS; PocketLink не устанавливает драйверы молча. Создаётся отдельная коллекция/профиль PocketLink Camera; существующие сцены не заменяются. Уже работающий OBS нужно сначала закрыть. В Discord выбери OBS Virtual Camera; звук микрофона выбирается отдельно. При первом запуске проверь изображение в OBS. Реальная камера с Discord в этой проверке не испытывалась: OBS и подключённого телефона нет.

## Заряд AJ159P и MCHOSE V9

Приёмники определяются, но подтверждённого чтения процента для фактически обнаруженных ревизий пока нет. Пустое значение означает «не поддерживается», а не нулевой заряд. Для AJ159P используй AJAZZ Driver (X), для V9 — настольный M HUB в режиме 2.4 ГГц; веб-драйвер MCHOSE гарнитуры не поддерживает. Не применяй прошивки AJ159 APEX к AJ159P.

## Проверки и ограничения

Сборка Android и lint: 0 ошибок, 40 предупреждений. Windows и установщик собраны; тесты проверяют TLS, сертификаты, очереди, возобновление передач, постоянный ключ, установку и откат, вредоносные пути ZIP, имена файлов и сохранение сцены OBS. Тесты расширений проходят. Панель Windows проверена на локальных тестовых данных.

Требования: Windows 10 2004/build 19041+ или Windows 11 x64, .NET 8 Desktop Runtime и WebView2; Android 10+. Отдельный Windows 10, Android 15/17, физический геймпад, веб-камера, реальная трансляция и работа YouTube с установленным расширением требуют проверки на устройствах. Остались два предупреждения совместимости библиотеки AudioSwitcher. Сборки предварительные.

Во всех релизах: APK, Windows ZIP, подписанный Firefox XPI, Chrome/Яндекс ZIP. Исходники Android опубликованы; полный локальный архив исходников сохранён отдельно без ключей и пользовательских данных.
