## Комплект каждого нового релиза

Каждый новый релиз PocketLink должен содержать все четыре готовых пакета, даже если изменился только один компонент:

| Файл | Назначение |
| --- | --- |
| PocketLink.apk | Android |
| PocketLink-Windows.zip | Windows |
| PocketLink-Firefox.xpi | Постоянное подписанное расширение Firefox |
| PocketLink-Chrome-Yandex.zip | Расширение Chrome и Яндекс Браузера |

Неизменившиеся пакеты копируются из последнего совместимого выпуска без пересборки и изменения подписи. В описании релиза указываются отдельные версии компонентов. Перед публикацией нужно сверить SHA-256 каждого перенесённого файла и проверить наличие всех четырёх в Assets. Source code не заменяет готовые установочные пакеты. Старые исторические релизы сохраняют свою историю; полный комплект обязательно добавляется в каждый новый выпуск.
