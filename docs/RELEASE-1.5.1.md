# PocketLink 1.5.1 / Windows 1.4.0

- На ПК: кнопка «Буфер → на телефон» в верхней панели, разделе буфера и меню значка возле часов. Читается текущий текст Windows, редактор и история остаются. Пустой/нетекстовый буфер не отправляется, текст ограничен 128 КБ, учитываются разрешения сопряжения.
- Android 1.5.1 сообщает результат записи буфера. ПК показывает подтверждение, отказ или тайм-аут. Со старым APK есть совместимая отправка без ложного подтверждения.
- Windows: новый раздел «Экран телефона» использует неизменённый официальный scrcpy 5.0.1 (включён вместе с ADB). USB/Wi-Fi, список устройств, сопряжение кодом, запуск/штатная остановка, журнал, готовые режимы, весь CLI через дополнительные параметры и локальный справочник.
- Готовые режимы: обычный/экономный/качество, запись MKV, только звук, камера, виртуальный дисплей, OTG, UHID/геймпад, погашенный экран. Android/аппаратные ограничения остаются, часть параметров зависит от ОС.
- Буфер scrcpy по умолчанию не синхронизируется автоматически. Код ADB не сохраняется и не передаётся через командную строку. Запуск без shell, отдельные аргументы; локальный интерфейс требует cookie и Origin.
- Исправлено отображение номера версии Windows (старый AppVersion был константой 1.2.0).
- Полная инструкция: docs/PHONE-MIRROR.md в репозитории. В каждом новом релизе все четыре пакета.

Проверки: Windows Release build/publish; Android assembleDebug + lintDebug — 0 ошибок, 40 предупреждений; прежние проверки протокола/безопасности; валидация адресов и аргументов ADB, отсутствие пакета, запуск настоящего scrcpy/ADB. UI проверен в браузере на демонстрационных данных: команда кнопки ui.clip.current, сохранение редактора, режим 720p/30 и раздел телефона. APK подписан прежним сертификатом.

Нет подключённого телефона и отдельного Windows 10: реальное видео, ввод, запись, звук, USB/Wi-Fi-сопряжение и ACK буфера пока не проверены на физическом устройстве. Проблема соединения друга оказалась из-за его VPN; менять защиту и протокол не потребовалось. Работающий установленный PocketLink не заменялся.

Windows: 10 2004 / build19041+ или 11, x64, .NET 8 Desktop Runtime. Android: 10+, включая 15. Для scrcpy нужно отдельно разрешить ADB на телефоне. Сначала выйдите из PocketLink и остановите scrcpy, затем распакуйте полный Windows ZIP поверх папки. Свои записи скопируйте перед заменой/удалением папки. APK установите поверх старого.
