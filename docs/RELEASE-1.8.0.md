# Android 1.8.0 / Windows 1.7.0 — проверка выпуска

Комплект пока локальный, публикация не выполнена.

- Прямая веб-камера телефона без scrcpy/ADB/OBS: отдельный компонент Windows11, разрешение камеры, остановка при разрыве соединения и отзыве доступа. Режимы480p/720p/1080p; реальная частота и разрешение зависят от телефона.
- Поиск функций на телефоне и ПК, каталог с переходами к нужной функции.
- Исправлены запрос окон Windows и появление диалога мониторов из скрытой вкладки.
- Добавлены причины ошибок scrcpy, безопасный повтор проверки ADB и инструкции для телефона.
- Исправлены поиск YouTube в Firefox, зависание команд и объяснение блокировки автопроигрывания.

Проверены14групп Windows-тестов, реальный генератор RGB32/NV12, зарегистрированная камера720p/1080p и полный путь Camera2Android→TLS→камера Windows. Android26проверок прошли; lint0ошибок41предупреждение. Живой Firefox: поиск20карточек, названия и ссылки обложек, громкость, скорость, перемотка, воспроизведение без звука/пауза. Воспроизведение со звуком в чистом профиле требует разрешения браузера.

Физический iQOO, Discord, отдельный Windows10, SMS/звонки и аппаратные HID-функции не проверены этим прогоном. На эмуляторе вход камеры720p: выход1080p не доказывает захват1080p на настоящем телефоне.

ВАЖНО: Firefox1.3.1 ожидает подписи Mozilla, страница остановлена CAPTCHA. В локальном комплекте сохранён подписанный Firefox1.3.0; исправление поиска для него ещё не доставлено. Chrome/Яндекс1.3.1 содержит исправление. Неподписанный ZIP не является устанавливаемым постоянным XPI.

Для обновления Windows с совсем старой версии закрой программу и распакуй полный WindowsZIP поверх постоянной папки. В версиях с поддержкой установщика обновление запускается внутри приложения. Настройки не входят в архив. AndroidAPK устанавливается поверх существующей версии с прежней подписью.
