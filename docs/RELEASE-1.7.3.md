# Android 1.7.3 / Windows 1.6.3

- Исправлен отдельный значок уведомлений Android: вместо старого квадрата используется белый силуэт нового знака P. Добавлен цветной значок приложения для уведомлений и одноцветный вариант для системных тем Android 13+.
- Верхняя системная полоса Windows следует светлой/тёмной теме PocketLink, в том числе теме телефона при включённой синхронизации. На Windows 11 задаются цвет полосы и цвет текста; на Windows 10 используется доступный системный тёмный режим рамки, точная заливка зависит от версии ОС.
- В Windows ZIP добавлен PocketLink.ico. При запуске обновляется значок существующих ярлыков PocketLink на рабочем столе и в меню «Пуск», только если они запускают именно текущий PocketLink.exe. Другие ярлыки и общий кэш значков не затрагиваются. Ярлык, ведущий в другую старую папку, нужно заменить ярлыком нового EXE; старый закреплённый значок при необходимости открепить и закрепить заново.
- Номер версии Windows внизу окна берётся из сборки: исправлена старая надпись 1.5.0.

Android assemble/lint: 0 ошибок, 38 предупреждений. Windows собран. Проверены сообщения темы (тёмная/светлая/с телефона/обычный браузер) и принятие Windows API цветов заголовка на отдельном невидимом тестовом окне, фон окна и версия сборки. Рабочая программа пользователя при тестировании не менялась. Внешний вид уведомления на реальном iQOO и отдельном Windows 10 пока не проверен. Остаются прежние предупреждения совместимости AudioSwitcher.

Установка поверх имеющейся версии сохраняет настройки и сопряжение. После обновления телефона открой PocketLink, чтобы постоянное уведомление пересоздалось. Если системная оболочка продолжает показывать старый значок, закрой уведомление/перезапусти приложение; переустановка с удалением данных не нужна.

Полный комплект: APK, Windows ZIP, подписанный Firefox 1.3.0, Chrome/Яндекс 1.3.0.
