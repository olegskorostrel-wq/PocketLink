# Микрофон телефона в Discord и играх

1. Обновите обе части PocketLink.
2. На ПК откройте «Микрофон телефона» и нажмите «Проверить микрофон».
3. Если компонент отсутствует, нажмите «Настроить микрофон». Откроется оригинальный установщик VB-CABLE из Windows-комплекта. Подтвердите запрос Windows, нажмите Install Driver, затем перезагрузите ПК.
4. Откройте микрофон PocketLink на телефоне, разрешите запись и нажмите «Включить / выключить микрофон». Для коротких фраз можно удерживать отдельную кнопку.
5. В Discord или игре выберите вход CABLE Output (VB-Audio Virtual Cable).

PocketLink автоматически выбирает CABLE Input на стороне ПК. Другой выход можно выбрать вручную, но колонки воспроизведут голос вслух. Настройки звуковых устройств Windows по умолчанию программа не меняет. Закрытие страницы микрофона и разрыв соединения останавливают передачу. Фоновая запись с закрытой страницей не поддерживается.

VB-CABLE — отдельный официальный компонент VB-Audio, включён без изменений. Это donationware: поддержать автора можно на https://vb-cable.com/ или https://shop.vb-audio.com/. Условия распространения: https://vb-audio.com/Services/licensing.htm. Для профессионального развёртывания требуются соответствующие лицензии VB-Audio.

Пакет проверяется по закреплённому SHA256 до распаковки и запуска. Установка возможна только по локальной кнопке на ПК. Телефон не может устанавливать драйверы. Компонент не устанавливается автоматически при запуске PocketLink.

Проверена подготовка оригинального пакета и отказ для повреждённого файла. Установка аудиодрайвера и реальный голос в Discord в этом прогоне не выполнялись.
