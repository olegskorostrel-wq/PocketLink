# Android 1.7.2 / Windows 1.6.2

Применён выбранный пользователем набор новых векторных значков:
- Главная — дом, вариант 1.
- Настройки — шестерёнка, вариант 1.
- Пульт — физический пульт с кнопками, вариант 2.
- Экран — значок трансляции, вариант 2.
- ПК — монитор с системным блоком, вариант 3.

Формы подготовлены в SVG и Android VectorDrawable, без растрового масштабирования. Цвет продолжает зависеть от выбранной темы. Главная и пульт теперь используют разные ресурсы; исправлен недостающий отступ между кнопками «Файлы и передача» и «Тачпад, клавиатура и мультимедиа».

На Windows обновлены значки обзора, трансляции и настроек; дополнительные символы пульта и компьютера включены в общий набор. Состав разделов Windows отличается от телефона, поэтому новые вкладки ради значков не добавлялись.

Сборки Android и Windows проходят. Android lint: 0 ошибок, 40 предупреждений; Windows: два прежних предупреждения совместимости AudioSwitcher. Изменение визуальное; реальный телефон не подключён для проверки. Функции и ограничения выпуска 1.7.1 сохранены.

Для старой Windows-версии: правой кнопкой по PocketLink возле часов → Выход; распаковать весь PocketLink-Windows.zip поверх прежней папки с заменой файлов; запустить PocketLink.exe. Настройки и сопряжения хранятся отдельно и сохраняются. В Windows 1.6.1+ следующие обновления устанавливаются через Настройки → Обновления Windows → Проверить → Скачать → Установить и перезапустить.

В комплекте APK, Windows ZIP, подписанный Firefox 1.3.0 и Chrome/Яндекс 1.3.0.
