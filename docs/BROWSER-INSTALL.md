# PocketLink YouTube 1.3.2

Исправление1.3.1: абсолютный адрес поиска, необходимый Firefox; таймауты поиска и ответа вкладки; сохранение сообщения об ошибке до следующей удачной команды. В живом Firefox проверены поиск, названия/обложки, громкость, скорость и перемотка.

Если браузер сообщает о запрете запуска видео, один раз нажмите Play во вкладке YouTube либо разрешите автопроигрывание для YouTube в настройках браузера. Расширение показывает эту причину и не меняет защитные настройки браузера самостоятельно. В чистом тестовом профиле воспроизведение было заблокировано этой политикой; это ограничение необходимо отличать от потери связи с PocketLink.

Исправления: диагностика подключения и неверного ключа; выбор вкладки YouTube; более устойчивый разбор результатов поиска и поддержка нового вида карточек; сохранена совместимость Android (поле id); одна неудачная команда не блокирует весь пакет; включение звука при повышении громкости. Уменьшены разрешения: нет доступа ко всем вкладкам через tabs permission.

## Firefox

Подписанный PocketLink-Firefox.xpi опубликован в GitHub Releases PocketLink. Скачайте XPI, откройте about:addons → шестерёнка → «Установить дополнение из файла» и выберите его. Установка постоянная, после перезапуска не исчезает. Firefox142+. Не используйте ZIP для подписи и не отключайте проверку подписей. Автоматическое получение следующих XPI пока не настроено.

## Chrome / Яндекс

Распаковать PocketLink-Chrome-Yandex.zip и загрузить папку через режим разработчика на chrome://extensions или browser://extensions. Такой способ не требует повторной загрузки после обычного перезапуска, пока папка сохранена; установка из магазина потребует отдельной публикации в магазине.

## Подключение

В окне расширения скопировать порт и ключ из раздела YouTube в PocketLink на ПК. Нажать «Сохранить и подключить», затем «Проверить соединение». Обновить уже открытые вкладки YouTube после установки/обновления расширения. При нескольких вкладках можно выбрать нужную.

В текущем Windows-сервере ключ сохраняется с защитой DPAPI: после первой настройки повторный ввод при обычном перезапуске не нужен. Ключ изменится при потере/сбросе его хранилища. Для полноэкранного режима браузер может требовать нажатие на ПК. Расширение не обходит это ограничение.

## Данные

Передаются название и идентификатор видео, состояние плеера и результаты поиска локальному PocketLink, затем сопряжённому телефону. Поисковый запрос выполняется на YouTube в текущем браузере. Ключ хранится в storage.local, не синхронизируется и отправляется только на localhost. Нет аналитики и сервера разработчика. Для Firefox добавлена декларация необходимых данных по актуальным правилам Mozilla; privacy.html находится в пакете.

## Проверки

Автоматические проверки Firefox/Chromium сообщений, управления плеером, старых и новых карточек поиска, сложного JSON, протокола id, пробуждения фонового процесса, неверного ключа, выбора вкладки и переподключения прошли. Подпись Mozilla получена. Сквозная работа с настоящим YouTube и установленными расширениями ещё требует проверки.

## Обновления расширения
Firefox1.3.2 содержит адрес автоматических обновлений из GitHub. Версии1.3.1 и старее нужно один раз обновить вручную: открыть новый подписанный PocketLink-Firefox.xpi в Firefox и подтвердить установку поверх прежнего. Настройки и ключ сохранятся. После этого Firefox самостоятельно проверяет новые версии при включённых автообновлениях дополнений. Ручная проверка: about:addons → шестерёнка → Проверить наличие обновлений. Публикация будущих обновлений требует подписанного XPI и обновления browser-updates/firefox.json с его версией, неизменяемой ссылкой и SHA256.

Chrome/Яндекс в режиме «Загрузить распакованное»: закройте страницы настроек расширения, распакуйте новый ZIP в прежнюю постоянную папку, затем на странице расширений нажмите его кнопку перезагрузки. Не удаляйте расширение: тогда локальный ключ сохраняется. Автообновление распакованной папки браузер не выполняет.
