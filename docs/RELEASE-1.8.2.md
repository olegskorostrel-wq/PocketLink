# Android 1.8.2 / Windows 1.7.2 — связь и отправка файлов

- Быстрые повторные подключения при открытом приложении или ожидающих файлах. Поиск изменившегося IP начинается после первой ошибки. Адрес из локальной сети проверяется прежним сертификатом ПК перед сохранением.
- Реакция на смену Wi-Fi и проверка состояния соединения при открытии приложения или отправке фото. Зависший TCP больше не держит ложный статус подключения до старого тайм-аута.
- Фото и файлы можно отправлять через «Поделиться», пока ПК ещё подключается: приватная копия сохраняется в очереди телефона. После восстановления связи передача начинается автоматически. Очередь сохраняется на диске; оригиналы не изменяются.
- Докачка после обрыва, проверка SHA256 и повтор подтверждения без второй копии файла на Windows. Задания привязаны к сертификату выбранного ПК и не отправляются другому компьютеру.
- Windows восстанавливает сетевой слушатель после временной ошибки; зависшие записи ограничены тайм-аутом. Увеличен допуск фоновой паузы Android. Во время копирования/передачи файла телефон кратковременно удерживает процессор активным.

Очередь ограничена 128 файлами и 8 ГБ. Для постановки в очередь нужно свободное место на телефоне. Её можно отменить в передачах. Для фоновой связи разрешите уведомления и работу PocketLink без ограничений батареи. Принудительная остановка приложения средствами Android блокирует фоновую работу до следующего запуска.

Обновите обе части: Android 1.8.2 и Windows 1.7.2. В каждом выпуске находятся APK, Windows ZIP, подписанное расширение Firefox и архив Chrome/Яндекс. Расширения не менялись.

Проверено на изолированном Windows-сервере и Android-эмуляторе: повторное подключение по ключу после трёх обрывов TCP, восстановление соединения без ответов, очередь при недоступном ПК, сохранение имени, дисковое восстановление очереди, контрольная сумма и повтор подтверждения без дубликата. Это не заменяет длительную проверку на физическом iQOO, с домашним роутером и конкретным VPN. Полное отсутствие обрывов Wi-Fi обещать нельзя; приложение должно восстанавливать связь и продолжать передачу.

Меню в трее Windows переработано: тема приложения (включая синхронизацию с телефоном), собственные контурные значки, статус подключения, увеличенные строки и разделители. Отправка буфера и файлов недоступна без подключённого телефона. Сохранены клавиатурная навигация и системная высокая контрастность. Проверен настоящий рендер светлого/тёмного меню.

Финальный прогон: 33 проверки Android прошли, включая обрыв посреди передачи файла 8 МБ и автоматическую докачку. 15 групп серверных проверок прошли; Android lint без ошибок. Подпись APK сохранена. Длительная проверка на физическом устройстве ещё нужна.
