# Android1.8.1 / Windows1.7.1

- Точные переходы поиска: раскрытие и прокрутка к разрешениям, подключению, оформлению и настройкам пульта на телефоне; буфер; нужные карточки камеры/помощи/обновлений/безопасности на ПК.
- Раздел микрофона на ПК со встроенной подготовкой оригинального VB-CABLE, проверкой целостности и запуском установщика по кнопке. Нужны подтверждение Windows и перезагрузка. Автоматический выбор входа на телефоне, постоянная передача или удержание кнопки.
- Настоящий установщик обновлений Windows проверен отдельными процессами: закрытие старой версии, замена файлов, запуск новой и сохранение тестовых настроек.
- Firefox1.3.2 содержит update_url для будущих автоматических обновлений с GitHub. Требуется однократная ручная установка версии с этим адресом. Проверка Mozilla прошла0ошибок0предупреждений; окончательная подпись проверяется отдельно.

scrcpy и физические устройства проверим позже по просьбе пользователя. Установка VB-CABLE и голос в Discord ещё не испытаны. Подробная инструкция: MICROPHONE.md. Chrome/Яндекс, установленные из распакованной папки, обновляются заменой файлов и кнопкой перезагрузки расширения; автоматическое обновление такого режима браузер не обеспечивает.
