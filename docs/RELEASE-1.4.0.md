# PocketLink 1.4.0: визуал от Claude

Применён предоставленный пользователем патч: обновлённая палитра светлой и тёмной темы, карточки с тонкими границами, сегменты режимов, индикатор активной вкладки, компактная верхняя плашка подключения, плитки команд с выделенным сочетанием, новые пустые состояния, сетка кнопок питания и компактные разделы настроек. Тачпад учитывает тему и показывает подсказку подключения.

Дополнительно ограничена ширина верхней плашки с длинным именем ПК; плитки сочетаний могут увеличиваться по высоте при крупном шрифте. Системные отступы, центрирование нижних подписей, свои кнопки/справочник и проверка обновлений сохранены. Сетевая защита, протокол и разрешения не изменялись.

ZIP и patch сверены: одинаковые изменения 8 файлов. Версия 1.4.0, versionCode 7, имя PocketLink. APK подписан прежним тестовым ключом: устанавливается поверх 1.3.x без удаления приложения.

Проверки: assembleDebug и lintDebug успешно, 0 ошибок / 38 предупреждений. Справочник104 сочетаний проверен на поддержку сервером. apksigner подтверждает действительную подпись и тот же сертификат SHA256 157c923d7557b8d1ce7643d4d47016d34ed196d9972c267dd963afe88f10d705.

Телефон через ADB недоступен, эмулятор не установлен: внешний вид, крупный шрифт и поворот проверены по коду, но визуальная проверка на устройстве ещё не выполнена. Сборка остаётся предварительной.

Обновить можно через Настройки → Обновления PocketLink → Проверить сейчас либо APK из релиза. Windows1.2.0 совместима, новая Windows-сборка для этого редизайна не требуется.
